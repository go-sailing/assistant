## 1. 设计目标与原则

### 1.1 设计目标

把"**说一句话就能管事**"和"**打开就能看清要做什么**"做到同等顺手，让对话入口与列表入口在体验上无缝互通。

### 1.2 设计原则

| 原则 | 说明 | 对应 PRD |
| --- | --- | --- |
| 移动优先 | 一切设计以手机单手操作为基准，PC 仅保证可打开不做适配 | 3.1、6.2 |
| 双入口同源 | 任务卡片、列表项视觉语言一致；对话里变了什么，列表里一眼能对上 | 3.3 |
| 写操作可反悔 | 删除、批量修改必须先预览再确认，危险操作永远有"取消" | C-04 |
| AI 不猜测 | 对象不明确时给候选让用户选，禁止"猜中即执行" | 5.5 |
| 云端状态透明 | 加载中、失败、断网均有明确状态，不制造"已保存"假象 | 4.3、6.2 |
| 轻量直达 | 记录任务的路径尽量短：列表页一键新建，助手页一句话创建 | T-01、C-02 |

## 2. 设计基准

### 2.1 画布与适配

- 设计稿基准宽度：**375pt（@2x 出图，即 750px）**；
- 纵向高度以 667pt（iPhone SE 3）为下限做兼容，以 852pt 为主力效果验收；
- 使用相对单位布局：宽度 `rem/%/flex`，间距与字号使用设计 Token；
- 刘海屏/底部横条：所有页面处理 `safe-area-inset-top / bottom`；底部 Tab 栏与输入栏必须叠加安全区高度；
- 横竖屏：MVP 仅支持竖屏锁定视觉（竖屏布局）。

### 2.2 触控与栅格

- 最小可点击热区：**44 × 44pt**（间距不足时热区可外扩，不可缩小）；
- 页面左右安全边距：16pt；内容栅格 4pt 基数（4 / 8 / 12 / 16 / 24 / 32）；
- 列表项高度 ≥ 56pt；
- 底部 Tab 栏高度：49pt + 安全区；对话输入栏：52pt + 安全区。

### 2.3 浏览器环境约束（H5 专项）

- 微信 WebView 内无浏览器导航栏：所有二级页面必须提供**页面内返回按钮**；
- 顶部预留浏览器地址栏变化空间，主操作不依赖浏览器 UI；
- 输入框聚焦时页面需自动上推，保证输入框与发送键不被软键盘遮挡；
- 不使用长按选中系统菜单承载业务操作，避免与 WebView 手势冲突。

## 3. 信息架构与全局导航

### 3.1 站点地图（IA）

```
启动页（未登录）
├── 引导页（产品介绍）
│   ├── 登录页（邮箱 + 密码）
│   └── 注册页（邮箱 + 密码 + 确认密码）
└── （已登录进入主框架）

主框架（底部 Tab × 2）
├── 任务 Tab
│   ├── 任务首页（筛选 + 任务列表 + 搜索入口 + 新建按钮）
│   ├── 任务详情页
│   ├── 新建/编辑任务页（表单）
│   ├── 搜索结果页
│   └── 清单管理
│       ├── 清单列表（重命名/删除）
│       └── 新建清单（行内输入）
└── 助手 Tab
    ├── 会话列表页（历史会话 + 新建会话）
    └── 对话页
        ├── 消息流（文本气泡 / 任务卡片 / 候选选择 / 确认条 / 系统提示）
        └── （卡片点击）→ 任务详情页（复用任务 Tab 的详情页）
```

### 3.2 全局导航规则

- 底部 Tab 栏在任务/助手两个一级页面常驻；进入二级页（详情、表单、对话页）时 Tab 栏隐藏，由顶部导航栏提供返回；
- 从对话卡片跳入任务详情：详情页左上角返回时回到原对话页（保持对话滚动位置与已加载消息）；
- 新建任务成功后返回来源页：来自列表则回到列表并定位高亮新任务 2s；来自对话则不跳转，仅在对话流中展示新任务卡片。

### 3.3 页面流转总览

```
登录/注册 → 任务首页 ⇄ 助手会话列表 ⇄ 对话页
              │  ↑          │
              ↓  └──────────┴（卡片点击）
           任务详情 ← 新建/编辑
              ↑
           搜索结果 / 清单管理
```

## 4. 核心用户流程（UX Flow）

### 4.1 注册与登录

```
打开 H5 → 引导页（3 屏轮播，可跳过）
  ├─ 已有账号 → 登录页：邮箱 + 密码 → 校验通过 → 任务首页
  │                            └─ 失败：输入框下方红字提示
  └─ 注册 → 注册页：邮箱 + 密码 + 确认密码
              → 前端校验（邮箱格式/密码强度/两次一致）
              → 提交成功 → 直接登录进入任务首页
  说明：MVP 无验证码、无邮箱激活；忘记密码不提供自助找回
        （登录页放"忘记密码？"→ 弹层文案：请联系客服/管理员，MVP 兜底）
```

**规则与状态：**
- 密码输入框默认密文，右侧"眼睛"图标切换明文；
- 提交按钮在必填项未填齐时置灰；提交中按钮 loading 且防重复点击；
- 错误提示就近显示（字段下方，红色 error 色），页面顶部不弹打断式 alert；
- 登录态保持：关闭浏览器再访问免重新登录（Token 由云端签发、端上仅保存会话凭证；不清算业务数据缓存的限制不适用于凭证）。

### 4.2 手动任务流程

```
任务首页 → 点右下"＋" → 新建任务页
  标题（必填，自动聚焦弹出键盘）
  备注 / 优先级（分段选择）/ 截止时间（日期+时间选择器）/ 所属清单（选择器）
  → 保存：按钮 loading → 成功返回列表，新项淡入并高亮 2s
  → 标题为空：标题框抖动 + 红字"请输入任务标题"
  → 截止时间早于现在：时间行下方橙色提示"该时间已过期"，仍可保存

任务首页 → 点任务项 → 任务详情
  ├─ 编辑 → 编辑任务页（复用表单）
  ├─ 勾选完成：按钮态切换 + completed_at 写入
  └─ 删除 → ActionSheet 二次确认 → 删除后返回列表（顶部 Toast"已删除"，MVP 无撤销）
```

### 4.3 对话任务流程

```
助手 Tab → 会话列表 → 进入（或新建）对话页
  用户输入 → 发送（气泡右上）→ 助手"正在处理…"→ 流式输出文本
    ├─ 纯回答：文本气泡
    ├─ 创建/单条更新：文本 + 任务卡片（卡片数据为云端最新值）
    ├─ 查询：文本简述 + 任务卡片组（1～N 张，>10 张折叠"查看全部"）
    ├─ 对象不明确：候选卡片组（每张带"是这个"按钮）→ 用户点选后继续执行
    ├─ 删除/批量：预览卡片（列出影响对象与条数）+ 确认条[取消][确认执行]
    └─ 异常：系统提示条（失败原因 + [重试]）
  切换到任务 Tab：卡片中涉及的增删改在列表中实时一致
```

### 4.4 断网与失败流程

- 任意云端请求超时/失败：内容区展示**错误占位态**（插画 + "加载失败" + [重试] 按钮），不展示旧数据（端上无缓存）；
- 对话发送时断网：消息气泡保留在输入态位置并标红色感叹号，点击感叹号可重发；助手侧不产生半截回复；
- 任务保存失败：停留在表单页，顶部出现错误条，**表单内容不丢失**（仅保存在页面内存中直至离开页面）。

> 线框为结构示意，视觉以第 6 章设计 Token 与高保真稿为准。

│                     │

- "开始使用"进入注册页；"去登录"进入登录页。

**登录页 / 注册页**

```
┌─────────────────────┐
│  ‹                  │
│                     │

│                     │

│  ┌───────────────┐  │
│  │ name@mail.com │  │
│  └───────────────┘  │
│  密码                │
│  ┌───────────────┐  │
│  │ ·········  👁 │  │
│  └───────────────┘  │

│                     │
│  [     登 录     ]  │
│  还没有账号？立即注册 │

```

- 注册页在密码下增加"确认密码"一行；密码强度条（弱/中/强，灰→橙→绿）实时反馈；
- 输入校验时机：失焦校验格式，提交时全量校验；错误信息出现在对应字段正下方，红色 12pt；

### 5.2 任务首页（任务 Tab 一级页）

```
┌─────────────────────┐
│  我的任务        🔍  │  ← 顶部导航：标题 + 搜索图标
│  [清单名 ▾]          │  ← 清单切换（下拉菜单，含"管理清单"）
│ 全部  未完成  已完成 │  ← 分段筛选控件
│ 按截止时间 ▾         │  ← 排序
├─────────────────────┤
│ ☐ 季度报告           │
│   工作 · 明天 15:00 🔴高 │
│ ─────────────────── │
│ ☑ 买菜          （划线灰）│
│   默认清单 · 今天    │
│ ─────────────────── │
│ ☐ 体检               │
│   生活 · 下周一 10:00 🟡中 │
│                     │
│   （空态见 5.6）     │
│                     │
│                ( ＋)│  ← 悬浮新建按钮（FAB）
├─────────────────────┤
│   任务      助手    │  ← 底部 Tab
└─────────────────────┘
```

**规格说明：**

- 顶部标题栏：44pt，白底；搜索图标点击进入搜索结果页；
- 清单切换：点击展开下拉菜单（默认清单置顶且无编辑入口；自定义清单右侧带齿轮 → 清单管理）；
- 分段筛选：三项等宽，选中项文字 primary 色 + 下方 2pt 指示条；
- 任务卡片（列表项）：
  - 左侧圆形勾选框 22pt：未完成灰边、已完成实心 primary + 对勾；
  - 标题：16pt 常规；已完成加删除线、文字置灰；
  - 副标题 12pt：`清单名 · 截止时间`；
  - 优先级标记紧贴时间：**形状 + 颜色双重编码**（高=三角、中=菱形、低=实心圆、无=空心圆），并提供 `aria-label`，避免只靠颜色传达信息；
  - 左滑露出操作按钮：[完成/恢复][删除]（删除红色）；
- 悬浮 FAB：56pt 圆形 primary 实心，白色"＋"，距右边距/底边 16pt（底边以 Tab 栏上沿计算）；
- 下拉刷新：系统风格 loading；失败时不插入脏数据，走错误占位态。

**对话组件规格：**

| 组件 | 规格 |
| --- | --- |
| 用户气泡 | 右对齐，primary 底白字，圆角 16（右下 4），最大宽度 76% |
| 助手文本 | 左对齐带头像，无底色，流式逐字输出，支持 Markdown 基础排版（加粗/列表） |
| 任务卡片 | 通栏白底卡片：勾选框 + 标题（可划线）+ 副标题（清单·时间·优先级），右侧">"暗示可点；点击跳任务详情；**卡片始终渲染云端最新数据** |
| 候选卡片 | 同任务卡片，底部内嵌"是这个"小按钮；点选后该消息折叠为"已选择：×××"并继续执行 |
| 确认条 | 浅红/浅黄提示底：操作描述（含影响条数）+ [取消]（次级按钮）+ [确认执行]（删除类红色实心，批量类 primary 实心）；确认前工具不执行 |
| 系统提示条 | 浅灰底居中，如"助手暂时不可用，请稍后重试 [重试]" |
| 时间分隔 | 会话跨天时插入日期分割线，当天显示"今天 HH:mm" |
| Loading | 助手头像旁三点呼吸动画 +"正在处理…"；流式开始后消失 |
| 发送失败 | 气泡左侧红色"!"，点击弹[重发][取消重发] |

**输入行为：**
- 输入框最高扩展至 4 行，超出滚动；
- 发送键：空内容置灰；流式输出期间允许继续输入但禁止再次发送（按钮 loading），防止会话并发；
- 助手执行写操作期间（确认条待确认除外），输入框上方不遮挡卡片，页面自动滚到最新消息。

### 5.7 通用状态页（空 / 错 / 加载）

| 状态 | 样式 | 适用 |
| --- | --- | --- |
| 首次空态 | 线性插画 + 文案 + 主按钮：任务页"还没有任务，点 ＋ 新建，或去助手说一句话"；助手页"开始和助手对话吧 [发起新对话]" | 列表/会话为空 |
| 筛选空态 | 小图标 +"当前筛选下没有任务"，无按钮 | 筛选无结果（区别于首次空态） |
| 加载态 | 任务列表：骨架屏（3～5 行灰色占位条）；对话：三点动画 | 首屏拉取 |
| 错误态 | 插画 +"加载失败"+ [重试]；不显示任何旧数据 | 网络/服务异常（云端架构无缓存） |
| Toast | 顶部下滑黑色半透明胶囊，2s 自动消失，不打断操作 | 保存成功、已删除等轻反馈 |

## 7. 关键交互细则

### 7.1 双入口一致性

- 同一条任务在列表、详情、聊天卡片三处的标题、状态、优先级、时间展示规则完全一致（同组件样式、同时间格式）；
- 在对话页停留期间若数据被其他端修改，再次渲染该卡片时以云端返回为准（卡片自带更新时间，不展示过期快照）；
- 完成态在任何入口勾选都即时生效：勾选动画 200ms → 云端成功后定格；云端失败则回弹原状态并 Toast"操作失败，请重试"。

### 7.2 时间与文案规则

| 场景 | 展示 |
| --- | --- |
| 今天 | `今天 HH:mm`（无具体时间则"今天"） |
| 明天/昨天 | `明天 HH:mm` / `昨天 HH:mm` |
| 本年其他日期 | `MM-DD HH:mm` |
| 跨年 | `YYYY-MM-DD HH:mm` |
| 逾期未完成 | 时间红色，详情页追加"已逾期 N 天" |
| 已完成 | 副标题时间保持原色，不展示逾期 |

### 7.3 AI 对话防错设计（对应 PRD 5.5/5.6）

1. **写操作白名单**：单条创建/编辑/完成可直接执行并出卡片；删除、批量写必须出现确认条；
2. **候选优先**：指令指向不明（多个匹配/无匹配）时，多匹配出候选卡片，无匹配由助手文本澄清，绝不创建模糊任务；
3. **批量预览**：确认条必须列出影响条数与最多 3 条任务摘要，多于 3 条折叠"等 N 项"；
4. **执行结果可核对**：完成后助手回复附任务卡片或数量摘要，用户可立即在任务 Tab 核对；
5. **流式输出中的工具动作不提前展示**：用户只在工具真正执行后看到结果卡片，避免模型"说了但没做"造成误解。

### 7.4 H5 手势与软键盘

- 左滑操作触发区为列表项右半区，边缘 20pt 让给浏览器返回手势；
- 表单页点击输入框以外区域收起键盘；对话页发送后自动收起键盘（可配置，但 MVP 默认收起）；
- 微信内下拉网页会触发浏览器回弹：列表容器使用内部滚动，避免与下拉刷新冲突。

## 8. 可访问性（A11y，MVP 基线）

- 正文与背景对比度 ≥ 4.5:1（已校验主色按钮白字、灰文对白/浅底）；
- 所有图标按钮提供 `aria-label`（如"新建任务""搜索""发送消息"）；
- 语义化标签：列表 `ul/li`、按钮 `button`、对话使用 `role="log"` 直播区域；
- 不以颜色作为唯一信息载体：优先级同时有颜色 + 旗标形状/文字，错误同时有色 + 文案；
- 支持系统字号放大到约 130% 不出现关键内容截断；
- 焦点态可见（outline 2pt primary 浅底），便于外接键盘/读屏操作。
