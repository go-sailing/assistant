## 0. 说明

### 0.1 用例优先级定义

| 级别 | 含义 |
| --- | --- |
| P0 | 核心主流程，阻塞发布（冒烟/回归必跑） |
| P1 | 重要功能与主要异常分支 |
| P2 | 边界、细节体验、兼容补充 |

### 0.2 用例编号规则

`TC-<模块>-<序号>`，模块：AUTH（账号）、LIST（清单）、TASK（任务）、CHAT（对话）、SYNC（双入口同源）、SEC（安全）、NFR（非功能/兼容/性能）。

### 0.3 通用前置条件

- 已准备测试邮箱（如 `qa_001@test.com`）与符合强度的密码（如 `Test1234`）；
- 浏览器：iOS Safari、Android Chrome、微信内置 WebView；
- 每个用例默认使用全新注册账号（除特别标注登录态/数据前置外）。

## 10. 测试数据与环境备注

- LLM 相关用例采用"真实模型 + 关键异常用 mock"结合：能力正确性走 DeepSeek 实测；超时/500/非法参数/幻觉 id 等走 mock 固定响应，保证可重复；
- 时间解析类用例（今天/明天/下周五、逾期 N 天）需固定服务端当前时间或在断言中相对计算；
- 限流用例在 staging 独立执行，避免污染其他测试；
- 每个用例结束清理测试账号及其数据（或使用一次性租户/库重置脚本）。
