## 9. 测试数据与环境备注

- **LLM 用例**：能力正确性走真实 DeepSeek（`deepseek-flash`）；超时/500/非法参数/幻觉 ID/未经查询直接带 task_id 等异常走 mock 固定响应（沿用 /tmp 桩服务模式，新增事件工具桩），保证可重复；
- **时间基准**：排期/冲突/月聚合类用例固定服务器时间或在断言中相对计算；跨时区用例准备 +8 与 0 时区两组设备/模拟参数；
- **冲突数据**：每轮冲突用例后清理，避免重叠日程污染月标记点与列表断言；冲突样本覆盖定时-定时、定时-全天、跨日、包含四种几何关系；
- **级联数据**：删任务级联用例使用独立任务，避免影响其他用例；校验 DB 层 CASCADE 时在事务回滚中验证或用一次性数据；
- **限流/压测**：日程写接口与 /chat 限流在 staging 独立窗口执行；压测库单独构造 3000 日程数据；
- **迁移**：在一份含 MVP 全量样例数据的库快照上执行 003 升级并校验 CHECK/索引，保留回滚脚本但不自动执行；
- 每用例结束清理测试账号及其任务、日程、会话数据（或库重置脚本）。
