## 1. 测试概述

### 1.1 测试对象与规模

| **合计** | | **254** |

实际执行：**引擎单元 33 项断言 + 接口/DB 210 项断言 + 浏览器 UI 20 项判定 + 真实 DeepSeek 对话 20 项断言 = 283 项断言**，覆盖 162 个用例的完整验收、30 个用例的部分验收。

### 1.2 测试环境与数据

- 后端：Node 22 + Express + TypeScript，`localhost:3100`（接口/DB 批跑）与 `localhost:3000`（浏览器与对话链路）
- 数据库：PostgreSQL 15 容器 `assistant-pg`
  - `assistant_v020_test`：全新建库，启动时自动执行迁移 001→005（`schema_migrations` 5 行）
  - `assistant_v020_upgrade`：**模拟 v0.1.0 存量库**（仅 001/002/003 + 1 用户/2 清单/5 任务/6 日程样例），用于迁移演练
- 前端：Vite dev server `localhost:5173`（`/api` 代理后端），Chromium 设备模拟（视口 549×652）
- LLM：**真实 DeepSeek**（`deepseek-flash`），未使用 mock
- 时间基准：服务端当前时间 **2026-09-16（周三）**；循环用例首次实例取 9-21（周一）起；时区对照 `Asia/Shanghai`(+08:00) 与 `UTC`
