## 0. 说明

### 0.1 用例优先级定义（沿用 MVP）

| 级别 | 含义 |

### 0.2 用例编号规则

- 新增三个模块独立编号：
  - **SERIES**（循环日程）：`TC-SERIES-001` 起；
  - **SUB**（子任务）：`TC-SUB-001` 起；
  - **NAV**（抽屉/FAB 导航重构）：`TC-NAV-001` 起；
- CHAT / SYNC / SEC / NFR / AUDIT 序号**延续 v0.1.0 文档**（v0.1.0 末号分别为 CHAT-078、SYNC-011、SEC-020、NFR 分段、AUDIT-008），本版从 CHAT-079、SYNC-012、SEC-021、NFR-010/020/026/039、AUDIT-009 接续；
- MVP 133 个 + v0.1.0 全部用例仍有效，作为本版回归集（见第 9 章）。

### 0.3 通用前置条件

- 已注册测试账号（如 `qa_020@test.com` / `Test1234`），除特别说明外每用例使用独立新账号；
- 浏览器：iOS Safari、Android Chrome、微信内置 WebView；
- LLM 用例默认日期以注入上下文 2026-09-16（周三）为准，时区默认 Asia/Shanghai（+8）；
- P1 功能若版本裁剪（R-08 本次及以后、R-12 循环搜索、T-09 搜索路径、T-10 到期聚合、A-08 混合意图），对应用例同步豁免并在测试报告中明示；
- 循环实例一律以服务端窗口展开结果为准，端上不做规则计算，断言时同时核对接口返回与界面展示。

- **LLM 用例**：能力正确性走真实 DeepSeek；规则非法、4010~4016 错误码、幻觉 key/parent_id、pending 超时/取消等异常走 mock 桩服务（新增循环工具与子任务工具桩），保证可重复；
- **时间基准**：循环类用例固定基准日 2026-09-16（周三），系列首次实例多取 9-21（周一）起；断言"下一次/共 N 次"时相对基准日计算；跨时区准备 +8 与 0 两组参数；
- **引擎边界数据集**：准备覆盖 31 日月（11 月）、28 日二月、2028 闰年、含第 5 个周 X 的月份、年末跨年 until 的固定样例；
- **冲突数据**：每轮后清理，避免污染月标记；候选几何关系覆盖定时-定时、定时-全天、循环-循环、包含、端点相接；
- **子树数据**：深度/级联/移动用例使用独立任务树，校验 DB CASCADE 在事务回滚或一次性数据上验证；子任务计数断言以递归 SQL 为准；
- **迁移**：在含 MVP+v0.1.0 全量样例的库快照上依次跑 004、005，校验新列 NULL 占比、索引与 CHECK、根任务数=任务总数；保留手工清理脚本但不纳入自动迁移；
- **导航专项**：三端分别验证系统返回手势（iOS 边缘、Android 物理/手势返回、微信胶囊/边缘）；a11y 用系统读屏实测；
- **限流/压测**：展开与子树接口、/chat 在 staging 独立窗口压测；压测库单独构造 200 活跃系列与 200 节点树；
- 每用例结束清理测试账号及其系列、覆盖、任务树、日程、会话数据（或库重置脚本）。
