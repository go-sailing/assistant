## 1. 设计目标与原则

### 1.1 设计目标

v0.3.0 无新业务领域，目标是把 v0.2.0 走查中暴露的 8 处摩擦修平：

1. **主页一步到位**——日历可大可小（月 ⇄ 周）、日期信息不重复、点日程一步到详情、整页滚动不被内部区域割裂；
2. **年度安排想定哪天就哪天**——"每年"重复的月日可选，且在保存前让人看清"第一次到底发生在什么时候"；
3. **宽屏不翻车**——窗口拉宽后内容居中一栏，日历格子不再随视口异常放大；
4. **弹层与入口守规矩**——清单名称输入区恢复正常可用；子任务的添加入口只留在"对的层级"；
5. **助手只有一个对话**——去掉会话列表这一层，"重新开始"由"清除聊天记录"承接。

### 1.2 设计原则（v0.3.0 新增/强化）

| 原则 | 说明 | 对应 PRD |
| --- | --- | --- |
| 沿用基线 | Design Token、页面骨架、循环/子任务/抽屉的既有规范全部沿用，本版只做增量与裁剪，不引入新色相、新字号档 | 全文 |
| 少一次点击 | 凡列表能直达的绝不加中间页；DayView 下线后详情页必须完整承接其操作，能力不允许随页面一起丢失 | C-03、4.4 |
| 状态可预见 | 折叠/展开开关始终可见且箭头指向动作结果；年规则首次实例跨年时预览必须明示；清除记录前置后果文案 | C-01、Y-01、A-01 |
| 信息只说一次 | 同一屏内同一信息（月份）只保留一个权威位置；被移除位置改为提供新信息（相对日/星期） | C-02 |
| 层级入口唯一 | "给谁加子任务"在每个层级只有一个位置：树宿主的添加入口；孙任务进详情页创建，列表行不放加号 | S-01 |

## 2. 设计基准

沿用 MVP/v0.1.0/v0.2.0 全部基准（375pt @2x、4pt 栅格、左右边距 16pt、最小热区 44pt、safe-area、周一为周起始），本版调整/新增：

- **新增布局 Token**：`--content-max-width: 480px`（宽屏中栏最大内容宽，见 5.7）；
- 日程主页滚动模型由"头部固定 + 列表区内部滚动"改为**整页滚动 + 标题条吸顶**（见 5.1）；
- 日程主页新增**折叠开关条**，高 32pt（含图示），触控热区不少于 44pt（见 5.2）；
- 新增一类组件形态：**底部表单弹层（FormSheet）**——在 AppActionSheet 遮罩/滑入规范上承载输入控件（见 5.5）；
- `/chat` 由"会话列表"改为"唯一对话页"，顶部为汉堡 + 标题 + 更多（见 5.6）；
- 无新增字号、无新增色相、无新图标（折叠箭头复用 chevron；清单弹层与清除菜单复用既有图标体系）。

## 4. 核心用户流程（UX Flow）

### 4.1 折叠看本周并直达详情

```
主页（展开态）
  └─ 点月历下沿折叠开关（箭头向上︿＋「折叠」）
       日历 250ms 收成一行（选中日所在周），开关变向下﹀＋「展开」
       ├─ ‹ › / 在日历区横滑：选中日按 ±7 天移动
       │    头部年月跟随；跨月时邻月标记点补齐；列表刷新
       ├─ 点周内某天：选中日切换，列表刷新（仍折叠）
       └─ 点列表任意 item
            → 直达 /calendar/:id（普通/任务/实例三类）
            → 操作完成返回 /calendar，折叠态与选中日保持
```

异常：跨月计数补齐失败 → 邻月格子不显示标记点（不阻断）；列表拉取失败 → 错误占位 + 重试（不展示旧数据）。

### 4.2 创建"每年指定日期"的循环日程

```
新建日程 → 标题、开始日期（2026-09-17 10:00）
  → 重复 → 每年
       「每年重复于」[ 9 月 ▾ ] [ 17 日 ▾ ]（默认带入开始月日）
       用户改为 6 / 1
       日选择 29/30/31 时下方常驻弱提示（月末回落）
  → 预览区：
       🔁 每年 6 月 1 日 10:00–11:00，长期重复
       首次安排：2027 年 6 月 1 日 周一      ← 跨年时新增的一行
  → 保存规则 → 表单重复行显示摘要 → 保存日程
```

- 未手动改月日时，修改开始日期联动选择器；手动改过后不再被覆盖（touched，沿用 v0.2.0 星期勾选策略）；
- 对话入口："每年 6 月 1 日体检"直达；"每年五月第一个周日"→ 助手追问/告知暂不支持，不猜。

### 4.3 清除聊天记录

```
/chat → 右上 ⋯
  → ActionSheet（仅一项，红色）：清除聊天记录
  → AppModal：
      清除聊天记录？
      将永久清除与助手的全部聊天记录，且不可恢复。
      任务与日程数据不会被删除。
            [取消]  [清除]（红）
  ├─ 取消：无变化，焦点回 ⋯
  └─ 清除：Toast「聊天记录已清除」→ 输入区保留、消息区切首次引导空态
```

### 4.4 新建 / 重命名清单

```
清单管理 → 右上 ＋
  → 底部表单弹层「新建清单」（输入框自动聚焦，键盘上推）
       名称全宽输入 →「确认」（空名置灰；提交中 loading 防重）
       或「取消」/ 遮罩 / 下滑 → 放弃
  ├─ 成功：弹层关闭，Toast「已新建清单」，列表入项
  └─ 失败：弹层内联红字，输入保留，键盘不收起
重命名：行内编辑图标 → 同构弹层（回填 + 全选，标题「重命名清单」）
```

### 4.5 给子任务添加下一级

```
任务首页 → 展开根任务
  ├─ 子树底部「＋ 添加子任务」：给根任务加直接子任务（唯一行内入口）
  └─ 每个子任务行右侧无＋；点子任务行
       → 任务详情页（该子任务）→ 子任务分区「＋ 添加子任务」
            ├─ 该任务深度 < 5：正常添加
            └─ 该任务深度 = 5：入口置灰 + 说明「任务最多支持 5 级层级」
```

### 4.6 宽屏与旧链（环境型流程）

```
窗口 ≥ 480px 内容宽：页面内容居中一栏（≤480px），两侧页面底色留白
旧书签 /calendar/day?date=2026-09-17 → 重定向 /calendar?date=2026-09-17（主页选中该日）
旧书签 /chat/123 → 重定向 /chat（进入唯一会话）
```

## 5. 页面设计规格（线框 + 说明）

> 线框为 375pt 基准的结构示意，视觉以第 6 章 Token 与高保真稿为准。仅绘制 v0.3.0 新增/改动页面与组件，沿用部分见 v0.2.0/v0.1.0/MVP 文档。

### 5.1 日程主页重构（展开态）

```
┌───────────────────────────┐
```

与 v0.2.0 的差异点：

| 区域 | v0.2.0 | v0.3.0 |
| --- | --- | --- |
| 滚动 | 导航 + 月历固定，列表区内部滚动，仅预览 3 条 + "查看全部" | 整页一个滚动容器；当日日程全量展示，无"查看全部/收起" |
| 列表标题 | `9月17日 周三 今天 共3项`（与头部月份重复） | `今天 周三` + `共 N 项`（5.3） |
| item 点击（普通/任务日程） | 进当日视图，再点一次进详情 | **直达详情**；全天/定时两类行均整行可点，右侧统一 chevron「›」暗示进入 |
| 全天日程 | 在当日视图有全天分区 | 主页列表置顶"全天"分组（组标题 + 卡片），定时日程在其后自然排列，不再渲染竖向时间轴 |
| 左滑完成/删除 | 当日视图行支持 | **下线**；完成（任务日程勾选）与删除一律进详情页操作 |
| 当前时间线 | 当日视图竖向时间轴 | 随 DayView 下线，不迁移（本版裁剪，见 PRD 1.3） |

- 行样式沿用现有列表行：时段列宽 84pt（全天行显示浅灰底「全天」徽标，复用 `--color-allday-bg`）、循环 repeat 图标、"已调整"胶囊、任务日程紫色类型标签全部保留；
- 行最小高度 52pt、整行 `<button>`， Chevron 12pt secondary；行分隔 1pt `--border-color`；
- 空态：`这天还没有安排`（沿用，位于标题条下方，页面仍可滚动到月历）；
- 加载：列表区骨架 3 行（沿用 300ms 延迟策略）；错误：错误占位 + 重试；均不清空月历选中态；
- 标题条吸顶：`position: sticky; top: 0`，白底 + 底部 1pt 分隔，z-index 低于折叠开关展开的弹层；导航栏随页面一起滚走（不再固定）。

### 5.2 折叠开关与折叠周形态

**开关条（展开/折叠共用一个控件）**

```
展开态：              折叠态：
   ──────────           ──────────
      ︿ 折叠               ﹀ 展开
   ──────────           ──────────
```

- 位置：月历 6 行（或折叠态 1 行）的下沿，与中栏等宽；
- 构成：chevron 16pt（primary 色）+ 文案 12pt（`--text-secondary`），水平居中；
- 热区：整行宽 × **不少于 44pt 高**（视觉条高 32pt，上下透明热区补足）；
- 箭头语义：**指向动作发生方向**——展开态显示向上 chevron「︿ 折叠」（日历将收起），折叠态显示向下「﹀ 展开」；
- 属性：`aria-expanded` 随态、`aria-label` 分别为"折叠月历，只看本周"/"展开月历"；
- 动效：月历容器高度过渡 250ms ease-out（与抽屉同曲线档），被收起的 5 行同时淡出（opacity 150ms）；reduced-motion 下直接显隐；
- 开关条在折叠/展开两种态下位置固定于"月历与列表之间"，不跟随内容跳动。

**折叠态主页**

```
┌───────────────────────────┐
│ ☰    ‹  2026年9月  ›  今天 │  头部月份 = 选中日所在月
│  一  二  三  四  五  六  日 │
│  14  15 [16] 17  18  19  20│  ← 仅选中日所在周一行（同样的格子尺寸）
│            ﹀ 展开          │
│ 明天 周四           共2项 ＋│  标题条规则同展开态
│  09:30–10:00  站会      › │
│  …                        │
└───────────────────────────┘
```

- 周行沿用月格组件同一套格子（数字 32pt 圆、标记点四态、补位日期置灰、今日描边、选中浅底），只是把 6 行数据裁成"包含选中日的那一周"；
- 折叠态交互矩阵：

| 操作 | 行为 |
| --- | --- |
| 点周内日期 | 切换选中日 → 列表刷新；保持折叠；点到邻月补位日时头部月份跟随 |
| 头部 ‹ / › | 选中日 ∓7 天；年月、周行、列表、「今天」按钮显隐全部跟随 |
| 日历区左右横滑 | 同 ‹ / ›（沿用 20pt 边缘避让与 40pt 横滑阈值） |
| 「今天」 | 选中日回今天、月份回本月；保持折叠 |
| 再点开关 | 展开 6 行月网格，定位到包含选中日的月份，**选中日不重置** |

- 周行跨月（如 9/28–10/4）时，该行需要两个月的计数数据：已拉过的月份走内存缓存，缺的月份随选中日切换按需补拉；补齐期间邻月格子无标记点（不出骨架、不闪烁），本月数据失败才走错误态；
- 折叠态**不持久化**：每次重新进入 /calendar 默认展开（同一次访问内翻页返回保持当前态，沿用组件存活）。

## 7. 关键交互细则

### 7.1 折叠态一致性

1. 折叠只改变日历视觉，**不改变数据语义**：选中日、列表内容、脏标记（eventSync）机制与展开态完全一致；
2. 折叠态按周移动时，头部月份永远等于选中日所在月；周行跨月时两侧日期可分别属于两个月，补位置灰规则同月网格；
3. 折叠态点今天/选日/翻周后立即展开，月网格必须落在包含该选中日的月份且该日处于选中态，不允许"展开后跳到别的月"；
4. 切换月份的动作只存在于展开态（‹ › 按月）；折叠态 ‹ › 一律按周——同一对箭头在两种态下语义不同，箭头旁无月份切换歧义（头部始终是当前选中月）；
5. 开关条位置与列表之间不插入额外间距跳动；动画进行中禁止重复触发（250ms 内忽略第二次点击）。

### 7.2 直达详情防落差

1. 三类 item 三跳：普通/任务 → 日程详情；循环实例 → 实例视角详情；不允许出现"点了没反应"或先闪一下 DayView；
2. 原 DayView 的编辑、删除、任务日程完成、循环作用域（仅本次/本次及以后/整条）、恢复本次全部在详情页可达——详情页 v0.2.0 已具备这些操作，本版只需回归确认，不新增交互；
3. 详情页返回主页时通过 `?date=` 回到原选中日；折叠态进入、折叠态返回（同次访问状态保留）；
4. 任务日程在主页不提供行内勾选（旧 DayView 左滑完成下线），勾选动作在详情页完成；对话卡片上的勾选不受影响。

### 7.3 年规则防错

1. 月/日选择器始终有值，不允许出现"未选择"空态，默认锚点月日即合理值；
2. 首次实例跨年/跨 interval 时，预览"首次安排"行是**强制可见项**，保存后的表单摘要与系列详情也应能看到首次/下一次时间；
3. touched 之后改开始日期不覆盖月日，但"时分"变化照常影响实例时刻（选择器只管日期）；
4. 2/29、31 日回落必须在两处有文案：选择器下方弱提示 + 摘要括注；
5. 对话里"每年第 N 个周 X"100% 追问/告知暂不支持，模型不得自行换算成具体日期。

### 7.4 表单弹层与软键盘

1. ListFormSheet 打开期间背景滚动冻结、遮罩可关；键盘弹起面板跟随上推（沿用既有 bottom-sheet 键盘策略），确认按钮始终可见可点；
2. 提交中锁定：按钮 spinner + 输入 disabled，防重复创建同名清单；
3. 失败不关弹层、不清文本、就近红字；键盘回车等价确认；
4. 重命名未做修改直接确认（同名回传）允许成功返回，不报错。

### 7.5 单会话与清除记录

1. 全局任何位置"进入助手"都落到同一个 /chat；不允许界面上出现第二个会话 id 入口（旧分享链接走重定向）；
2. 清除记录是危险操作但**不是高频危险**：菜单只放一项减少误触层级，确认弹窗默认焦点在[取消]；
3. 清除后会话 id 不变、草稿保留、引导空态立即可输入；不弹"去新建会话"之类多余动作；
4. 清除不动任务/日程/清单数据——确认文案必须把这句写明，且操作后这些页面数据实测无变化；
5. 多端：另一端重新进入 /chat 拉到空历史即可，不做实时推送（PRD 7.6）。

### 7.6 层级入口防误触

1. 行尾＋移除后，子任务行的可点元素只剩：展开箭头（有下级时）、复选框、行主体（进详情）；三个热区互不重叠，箭头与行主体 `@click.stop` 隔离沿用既有实现；
2. "添加子任务"在首页语义恒为"给根任务加直接子任务"；在详情页语义恒为"给本页主任务加直接子任务"——文案不需要变化，页面上下文即说明对象；
3. 第 5 级置灰同时给出文字说明，不能只灰不可点；4013 拦截时的 Toast 文案与置灰说明一致。

### 7.7 滚动与手势（H5 追加）

- 主页整页滚动后，月历区横滑（翻月/翻周）与纵向滚动的判定沿用 40pt 横向阈值；纵向滚动起手后不再触发翻页；
- 吸顶标题条不拦截触摸；FAB 仅自身热区响应，不挡列表滚动；
- 微信 WebView 软键盘弹起/收起不应造成中栏横向位移；页面全程不出现横向滚动条。

## 8. 可访问性（A11y，增量）

- **折叠开关**：`aria-expanded`、`aria-controls` 指向月历容器；月历容器折叠时加 `aria-hidden` 的非当前周行（或直接不渲染，推荐不渲染余行，读屏不到幽灵日期）；开关文案随态变化，读屏可感知状态与动作；
- **周行日期格**：`aria-label` 沿用月格完整句式（`9月16日 周三，2 个日程，含循环日程`），补位日期正常读出（切换选中需要）；标记点 `aria-hidden`；
- **列表行**：整行按钮 `aria-label="{时段} {标题}"`（沿用）；全天行读出"全天 {标题}"；行右侧 chevron `aria-hidden`；
- **yearly 选择器**：两个 `<select>` 分别带 `aria-label="月份"`、`aria-label="日期"`；月末提示与首次安排行用 `aria-live="polite"`（选择变化时读屏播报），或通过 `aria-describedby` 关联到选择器；
- **ListFormSheet**：容器 `role="dialog" aria-modal="true" aria-labelledby={标题id}`；打开焦点入输入框，Tab 焦点在输入框/确认/取消间循环；关闭还焦＋或编辑图标；错误红字 `role="alert"`；
- **清除记录**：菜单项 danger 仅靠颜色不够——文案本身即"清除聊天记录"语义充分；确认弹窗 `aria-modal`，默认焦点[取消]；成功 Toast 区域 `aria-live="polite"`；
- **子任务树**：移除＋按钮后行内可点元素减少，读屏顺序更干净；第 5 级置灰入口 `aria-disabled="true"` + 说明文本关联；
- **中栏宽屏**：内容居中不得导致读屏焦点顺序变化（DOM 顺序不变，仅视觉居中）；
- **对比度**：折叠文案 secondary（#6B7080 白底 4.6:1）、首次安排 primary、置灰说明 secondary 均满足 ≥4.5:1；
- **字号 130%**：折叠开关允许增高不截断；标题条日期允许换行但不与计数重叠；yearly 双选择器允许纵向堆叠不溢出；清单弹层按钮不被键盘裁切。

### 9.2 UI 走查验收要点

1. **折叠**：开关位置/热区/箭头方向/aria 正确；折叠后仅一周；‹ › 与横滑按周、跨月年月跟随、邻月标记点补齐无残留；今天按钮保态；展开定位不跳月；动画 250ms 与 reduced-motion 降级；

3. **标题去重**：任何选中日下屏幕内月份只出现一次（头部）；今/明/昨/普通四种标题文案正确；
4. **直达详情**：普通/任务/循环三类 item 均一跳到正确详情；DayView 操作（编辑/删除/完成/作用域/恢复）在详情页全部可达；旧链重定向带回 date；
5. **宽屏**：1024/1280/1920 三档下中栏 480 居中、月格不放大、无横向滚动；Sheet/Modal 居中贴底/居中、遮罩通铺；FAB 贴视口右下；抽屉不受中栏影响；

7. **清单弹层**：输入框全宽可正常输入、自动聚焦、空名禁提交、loading 防重、回车提交、失败保留文本、遮罩/取消关闭、键盘不遮挡按钮；重命名回填全选；
8. **子任务入口**：三处 SubtaskRow 无＋；首页只能给根任务加；孙任务只能详情页加；5 级置灰 + 说明；勾选/展开/进度不回归；
9. **单会话**：/chat 直接对话、汉堡一级页、标题固定"助手"、无任何列表/重命名/新建会话入口；FAB 在 /chat 隐藏、在日程/任务页正常；/chat/:id 重定向；
10. **清除记录**：菜单 → 确认（默认焦点取消、文案含不可恢复 + 不删任务日程）→ Toast + 空态；草稿保留；任务/日程/清单数据无变化；失败不丢消息；
11. **状态与 A11y**：骨架延迟/空/错三态不展示旧数据；dialog/aria-expanded/controls/labelledby/alert/disabled 齐全；对比度与 130% 字号抽查通过；
12. **兼容**：iOS Safari / Android Chrome / 微信 WebView 软键盘上推、横滑与滚动冲突、边缘 20pt 避让；320/360/390pt 宽度无错位。
