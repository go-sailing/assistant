## 0. 说明

### 0.1 用例优先级定义（沿用 v0.2.0）

| 级别 | 含义 |
| --- | --- |
| P0 | 核心主流程，阻塞发布（冒烟/回归必跑） |
| P1 | 重要功能与主要异常分支 |
| P2 | 边界、细节体验、兼容补充 |

### 0.2 用例编号规则

- 新增四个模块独立编号：
  - **CAL**（日历主页重构：折叠/去重/直达/宽屏）：`TC-CAL-001` 起；
  - **YEAR**（yearly 指定月日）：`TC-YEAR-001` 起；
  - **LIST**（清单新建/重命名弹层）：`TC-LIST-001` 起；
  - **CONV**（助手单会话，含迁移 006）：`TC-CONV-001` 起；
- SERIES / SUB / NAV / CHAT / SYNC / SEC / NFR / AUDIT **延续 v0.2.0 末号**：SUB 从 060、NAV 从 026、CHAT 从 115、SYNC 从 020、SEC 从 031、NFR 启用 050 新段、AUDIT 从 015 接续（v0.2.0 末号分别为 SERIES-089、SUB-059、NAV-025、CHAT-114、SYNC-019、SEC-030、NFR-043、AUDIT-014）；
- MVP 133 个 + v0.1.0 + v0.2.0 全部用例仍有效，作为本版回归集（见第 12 章）。

### 0.3 通用前置条件

- 已注册测试账号（如 `qa_030@test.com` / `Test1234`），除特别说明外每用例使用独立新账号；
- 浏览器：iOS Safari、Android Chrome、微信内置 WebView；宽屏用例补充桌面 Chrome 1024/1280/1920px；
- 本版时间基准固定为 **2026-09-17（周四）**，时区默认 Asia/Shanghai（+8）；选中日自然周固定示例：9-14（周一）～9-20（周日）；跨月周示例：8-31～9-6、9-28～10-4；
- yearly 用例的 anchor（首次开始时间）以各用例步骤显式给出；"首次实例/共 N 次"断言相对 anchor 与基准日双重核对；
- 循环实例一律以服务端窗口展开结果为准，端上不做规则计算；会话与消息断言同时核对接口返回、界面展示与数据库行。
