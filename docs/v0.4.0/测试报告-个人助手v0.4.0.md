## 1. 测试概述

### 1.1 范围与方法

按用例文档的 14 个模块（WC / LUN / HOME / TREE / PROP / MD / ANCHOR / EVT / AUTH / ME / SYNC / SEC / NFR / AUDIT）执行，采用四层方法：

| 层级 | 手段 | 覆盖模块 |
| --- | --- | --- |
| 引擎级 | `tsx` 脚本直调 `recurrence/engine`、`summary`、`lunar.service`、`workday.service`（纯函数 + 进程内缓存，不依赖 HTTP） | WC 判定与展开、LUN 换算与年度循环、公历循环回归 |
| 服务级 | 直调 `eventService.monthly/list/resolveLunar`，覆盖读模型与性能 | LUN 2.2/2.4、NFR 性能 |
| 接口级 | `curl` 打通真实 HTTP（含 zod 校验、错误码、限流），并回查数据库行 | WC 校验/角标/作用域、LUN 校验/单次/冲突、EVT、AUTH、ME、SYNC、SEC |
| 界面/对话级 | 真实浏览器（2 个并行浏览器代理）走查交互与真实 LLM 对话 | HOME、TREE、MD、ANCHOR、PROP、WC/LUN 表单、WC/LUN 对话、ME UI、AUTH UI |

**独立证据原则**：法定日历种子以国务院办公厅公告反推核对；农历换算不采用"用库校验库"，而以**官方公告可反推的锚点**（如公告称 2026-02-15 为农历腊月二十八 → 正月初一即 2/17）+ 历法不变式（月长、春节间隔、节气数与间隔）作为独立判据。
