### 0.3 通用前置条件

- 已注册测试账号（如 `qa040@test.com / Test1234`），除特别说明外每用例独立新账号；
- 浏览器/容器：iOS Safari、Android Chrome、微信内置 WebView；桌面 Chrome 1024/1280/1920px 补宽屏；
- 本版**时间基准固定 2026-09-18（周五）**，时区 Asia/Shanghai（+8）；
- 服务端已应用迁移 007/008/009（法定日历种子以国办发明电〔2024〕10 号、〔2025〕7 号为准）；
- 农历对拍日期表（lunar-javascript vs 权威历表）为引擎用例的 fixture 文件，**凡标注「历表 fixture」的日期以经评审确认的 fixture 为准**；
- 循环实例一律以服务端窗口展开结果为准；会话断言同时核对接口、界面与数据库行；
- LLM 用例使用真实 DeepSeek（deepseek-flash），每个意图允许重试 2 次以容忍模型抖动，但"必须/禁止"类断言以服务端规则与校验为最终判据。
