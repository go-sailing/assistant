### 0.3 通用前置条件

- 已注册测试账号（如 `qa050a@test.com / Test1234`），除特别说明外每用例独立新账号；
- 浏览器/容器：iOS Safari、Android Chrome、微信内置 WebView；桌面 Chrome 1024/1280/1920px 补宽屏；
- 本版**时间基准固定 2026-09-18（周五）**，时区 Asia/Shanghai（+8）；
- 服务端已应用迁移 **010**（`long_term_memories` 新表 + `conversations.context_summary` / `compacted_until_id` 两列）；
- LLM 用例使用真实 DeepSeek（deepseek-flash），每个意图允许重试 2 次以容忍模型抖动，但"必须/禁止"类断言以服务端规则、校验与工具调用序列为最终判据；纯函数/服务级用例使用 Jest + mock LLM；
- 压缩触发类用例默认通过测试环境配置（`CHAT_MODEL_CONTEXT_TOKENS` 调小或 `CHAT_COMPACT_THRESHOLD_RATIO` 调高）构造水位，不依赖真实聊满 64000 token；端到端用例另行构造 60+ 轮真实长对话；
- 会话断言同时核对接口响应、界面表现与数据库行（messages.payload、conversations 两列、long_term_memories 行）。
