## 7. 重点验证结论

### 7.1 迁移 011（最受关注项）

在独立 schema 内从 001 基线造 v0.5.0 形态数据（T1→T2→T3 三层子树、第二棵树 T4→T5、2 条任务日程、1 条普通日程、1 条长期记忆、1 个会话）后升级 011：

- **一次性拆散**：5 个原 `parent_id` 非空任务**一条 UPDATE 全部置 NULL**，任意深度均命中；
- **数据零丢失**：标题/备注/优先级/`due_at`/`status`/`completed_at` 逐字段一致；`events.task_id` 指向不变；记忆与会话行数不变；
- **幂等**：重复执行 011 → 拆散命中 0 行、约束与索引不重复（各 1/1）、无报错；
- **谓词守卫**：升级后新建「项目 + 成员」再重放 011，成员 `parent_id` **未被置空**；
- 列定义核验：`varchar(16)` / `NOT NULL` / 默认 `'normal'` / 列注释存在；CHECK 接受 `normal|project`，拒绝 `task` / `NULL` / 空串；`idx_tasks_user_task_type`、`idx_tasks_user_project` 均存在。

### 7.2 项目能力（服务端）

- **4017**（项目须顶层）：创建携带 `parent_id`、挂到普通任务/另一项目、互挂/嵌套全部 409/4017，库内无层级写入；
- **4018**（普通任务无子任务）：创建/PATCH 指向普通任务、指向成员、自挂载、成员再拆均 409/4018；库中**无「父非项目」的层级行**；
- **合法挂载与约束**：成员挂到项目成功（`parent_id` 正确、`member_total` +1）；跨清单 4014；成员独立改清单 4014；项目改清单时项目与直接成员同语句迁移；
- **容量**：前 200 个成员全部成功、第 201 个 1001「项目成员最多 200 个」；满员项目内改成员不误拒（`excludeTaskId` 生效）；
- **进度**：0/3 → 1/3 实时刷新；全部成员完成项目仍为 todo；`subtask_*` 与 `member_*` 等项目同值、普通任务恒 0；
- **4010 级联**：未带 cascade 返回 409/4010 且**不写库**，`details` 同时含 `incomplete_member_count` 与别名 `incomplete_descendant_count`、`cascade_required=true`；带 cascade 后项目与全部未完成成员一并完成；取消完成非对称（仅项目回 todo）；重复完成不刷新 `completed_at`；
- **preview-remove / 删除**：项目+3 成员+3 日程 → `{4, 3}`；空项目 `{1, 0}`；DELETE 后库中无残留、无 `task_id` 悬空日程；不存在/越权统一 404 同文案；
- **subtree 收窄**：项目返回 `[项目, ...直接成员]`（成员 depth=2）；普通任务仅返回自身；>200 成员 1001；越权 404；
- **自动唤醒**：新建未完成成员唤醒已完成项目（`revived_parent` + 日志 `project_auto_revived`）；已完成成员移入不唤醒。

### 7.3 入口与结构收敛（静态 + 产物）

- `/settings` 危险区整组消失（模板、脚本、样式三层核验），`/me` 仍保留退出登录与注销账号；
- `AppNavBar` 由路由集合统一渲染菜单按钮（`me`/`settings` 在集合内），`renderBack = showBack && !showMenu`，下级页（改密/记忆）保持返回；
- 应用外壳**无任何触摸绑定**（右滑手势与常量零残留）；`AppFAB.vue` 已删除，产物中无「打开助手」类节点；
- 日程主页头部为「菜单 · 月份 · ＋」，无 `‹ ›`/头部「今天」、无列表标题行（`.month__bar`）、无折叠开关行（`.month__toggle`）；浮动「今日」为白底胶囊且仅选中日 ≠ 今天时出现；
- 日历手势常量与状态机齐备：32px 阈值、1.5 方向锁、8px 方向观察期、250ms 动画互斥、`fired` 一次手势一次、`touchstart/touchmove` 全 passive、`lastView` 含 `collapsed`（TTL 5 分钟）；
- 表单拆分：`/calendar/new` → 普通日程（无类型开关）、`/calendar/task/new` → 任务日程（任务锁定、无重复行、无农历切换、缺 `task_id` 阻断保存）、`/calendar/:id/edit` → 按 `event_type` 分流、`/calendar/tasks` → 302 `/tasks`；
- 详情收敛：循环实例底部两按钮与样式零残留，头部「编辑」→ScopeSheet（三作用域），已取消实例保留「恢复本次安排」。

## 8. 结论与建议

### 8.1 结论

1. **服务端 v0.6.0 全部功能可交付**：项目管理（迁移 011、项目/成员、4017/4018/4014、容量、进度、4010 级联、preview-remove 删除、subtree 收窄、自动唤醒）、LLM 项目能力（真实 ID 挂载、项目结果组轮末聚合、子任务诉求引导）全部按 PRD/SDD 通过；
2. **迁移安全**：011 在类生产快照上「拆散 + 零丢失 + 幂等 + 守卫」四要素全部验证通过，可进入发布；
3. **入口与结构收敛达标**：UI-01~04、CAL-01/02（结构层）、FRM-01（结构层）、DTL-01 的静态断言 68/68 通过；
