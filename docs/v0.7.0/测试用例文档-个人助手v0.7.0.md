### 0.3 通用前置条件

- 服务端已应用迁移 **012_agent_proxy.sql**（agents / tasks.agent_* / agent_task_logs / 约束 / 索引）与 **013_task_list_retire.sql**（清单归位 + 自定义清单清理），均为单文件单事务、幂等；
- 已注册测试账号（如 `qa070a@test.com / Test1234`），除特别说明外每用例独立新账号；
- **MCP 测试客户端**：Node 脚本 `mcp-client.mjs`（原生 fetch 模拟 MCP 客户端：initialize → notifications/initialized → tools/list → tools/call），支持指定 `Authorization` 与自定义 JSON-RPC body；另备**真实工具 E2E**（Claude Code / opencode 至少各 1 次人工验证）；
- 浏览器/容器：iOS Safari、Android Chrome、微信内置 WebView；桌面 Chrome 1024/1280/1920px 补宽屏；
- 本版**时间基准固定 2026-09-19（周六）**，时区 Asia/Shanghai（+8）；日期锚点沿用 v0.6.0 测试用例文档 §0.4；
- LLM 用例使用真实模型，每个意图允许重试 2 次以容忍模型抖动，但「必须/禁止」类断言以服务端规则、校验与工具调用序列为最终判据；纯函数/服务级用例使用 Jest + mock LLM；
- 接口断言同时核对**接口响应、界面表现与数据库行**（tasks.agent_state/agent_id/agent_queued_at/status、agents、agent_task_logs、tool_invocations、schema_migrations）；
- 计时类用例（P95、≤10s）在同一环境连续执行 20 次取 P95，或单次断言留 20% 余量；长轮询用例使用 `timeout_ms` 缩短等待以控制用例时长，超时/上限类用例例外。
