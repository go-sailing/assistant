### 1.2 执行方法说明（口径）

- **静态核验**用于端上结构类要求（模块/页面/组件/API/Store/类型/图标/token 零残留、路由重定向、文档与配置项、埋点口径），不做真机点击；
- **CAL-04 跟手联动**采用「纯函数单测（`utils/shape.ts` 真实导入）+ 组件无头执行（真实 touch 处理器、真实 `mapProgress/settleTarget/easeOutCubic`、真实 `MonthView` 状态机）+ 源码结构核验」三轨；真机肌感、帧率与 10/10 复测不在本轮范围（见 §6）；
- 计时类指标仅在**同环境同批次**内比较（首屏 P95、包体 gzip 与 v0.7.0 基线对比：v0.7.0 基线由 `git archive HEAD` 提取 v0.7.0 源码后单独构建取得）；
- 迁移用例在**真实 postgres** 上执行，含全新库、幂等重放、注入失败语句的单事务回滚、v0.7.0 类生产快照升级、10 万行大库五组独立演练，结果留档；
- 每轮脚本执行结果以 JSON 落档，报告中的数字均取自该轮实测输出。
