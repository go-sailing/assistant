### 0.3 通用前置条件

- 服务端已应用迁移 **001 → 014**（`014_retire_task_project_agent.sql`；`db/migrate.ts` 单文件 `BEGIN…COMMIT/ROLLBACK` 单事务、幂等可重放），`DB_AUTO_MIGRATE=true`；
- 已注册测试账号（如 `qa080a@test.com / Test1234`），除特别说明外每用例独立新账号；
- 浏览器/容器：iOS Safari、Android Chrome、微信内置 WebView；桌面 Chrome 1024/1280/1920px 补宽屏；
- 本版**时间基准固定 2026-09-26（周六）**，时区 Asia/Shanghai（+8）；日期锚点沿用 v0.6.0 测试用例文档 §0.4；
- 本版为**减法版本**，判定基线一律为「**删除后行为**」而非 v0.7.0 的「存在行为」：删掉的能力不是缺陷，残留才是缺陷；
- 接口断言同时核对**接口响应、界面表现与数据库行**（`events` 的 `event_type`/`task_id`/`title`、`schema_migrations`、保留表 `tasks`/`task_lists`/`agents`/`agent_task_logs` 的**未被写入**）；
- LLM 用例使用真实模型，每个意图允许重试 2 次以容忍模型抖动，但「必须/禁止」类断言以**服务端规则、工具表、工具调用序列**为最终判据；纯函数/服务级用例使用 Jest + mock LLM；
- 手势类用例（CAL）以**纯函数单测 + 真机行为断言**双轨判定，纯函数以 `src/web/src/utils/shape.ts` 导出为准；
- 计时类用例（P95、≤250ms、≥55fps）在同一环境连续执行 20 次取 P95，或单次断言留 20% 余量。

## 4. 日程主页折叠 / 展开跟手联动（CAL，CAL-04）

> 需求：PRD 5.1~5.8；设计：SDD 11.1~11.13、UXUI 7.1~7.5。
> 判定基准：连续量 `p ∈ [0,1]`（1 全展开 / 0 全折叠）；跟手映射 `p = clamp(p₀ + dy/range)`（`dy` 向下为正）；端点阻尼增量 ×0.4；吸附「行程 ≥50% 或 |v| ≥0.3px/ms」；动画 ≤250ms；起手区 = 日历区 ∪ 列表顶部。
> 核心不变量（I7/I8）：只存在整月↔选中周两态；一次手势只切换一次；无半开残留；惯性滚动不触发形态。
