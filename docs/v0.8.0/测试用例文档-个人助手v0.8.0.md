### 0.3 通用前置条件

- 服务端已应用迁移 **014_project_extract.sql**（projects 表 + tasks 去 `task_type`/`parent_id` + 加 `project_id` + 数据搬迁 + 断言校验），单文件单事务、幂等；迁移前须保留 **v0.7.0 类生产库快照**（含项目、项目成员、项目关联日程、已完成项目）；
- 已注册测试账号（如 `qa080a@test.com / Test1234`），除特别说明外每用例独立新账号；
- **测试数据集（固定）**：
  - 账号 A：2 个项目（「装修项目」3 个成员、其中 1 个已完成；「季度述职」2 个成员）+ 2 个独立任务（无项目）+ 1 个"项目关联日程"（迁移前构造）；
  - 账号 B：无项目、无任务（用于空态）；
  - 账号 C：120 个项目（用于筛选器弹层滚动与搜索）；账号 D：单项目成员恰好 200（用于上限）；
  - 账号 E：任务已完成且曾指派代理（用于 DTL 的队列一致性）、任务已完成且曾有日程（用于可选提示行）；
- 浏览器/容器：iOS Safari、Android Chrome、微信内置 WebView；桌面 Chrome 1024/1280/1920px 补宽屏；
- 本版**时间基准固定 2026-09-20（周日）**，时区 Asia/Shanghai（+8）；日期锚点沿用 v0.6.0/v0.7.0 测试用例文档 §0.4；
- LLM 用例使用真实模型，每个意图允许重试 2 次以容忍模型抖动，但「必须/禁止」类断言以服务端规则、校验与工具调用序列为最终判据；
- 接口断言同时核对**接口响应、界面表现与数据库行**（projects、tasks.project_id/status/agent_*、events、agent_task_logs、schema_migrations）；
- 计时类用例（P95、≤1 帧、≤300ms）在同一环境连续执行 20 次取 P95，或单次断言留 20% 余量；手势类用例一律**真机执行**，桌面浏览器仅作辅助。
