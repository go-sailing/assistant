- 远程 v0.8.0 的项目域成果——**已被 v0.9.0 的下线决策覆盖**，随能力一起退役（代码删除，数据保留）；
- 远程 v0.8.0 的其余成果——按「是否仍适用于只保留日程的产品」逐项判定保留或退役（见 §3）。
